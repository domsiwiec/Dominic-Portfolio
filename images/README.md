# Images

Every photo slot on the site already points at a filename in this folder. Drop a
file in with the matching name and it appears automatically. Until then the slot
shows a dashed placeholder, so nothing ever looks broken.

There is nothing to edit in the HTML. The page checks whether the image loaded
and swaps the placeholder out on its own.

## Sizing

Keep each photo under roughly 250 KB so pages stay fast. Good target widths:

* Card and gallery photos: 900 to 1200 px wide
* Wide banners: 1500 px wide
* Portrait gallery photos: 760 px wide, 4:5

Send me the originals if you would rather I crop and compress them for you.
