# Images

Drop your photos in this folder, then open the matching HTML file and:

1. Find the `<!-- <img src="images/..." /> -->` line for that slot
2. Delete the `<!--` and `-->` around it
3. Delete the `<span class="photo-slot-label">...</span>` line directly below it
